# Design System: André Valenga — Quiet Evidence

## North star

The portfolio should feel like a calm conversation with a senior data professional: clear, structured and credible. Real project evidence carries the visual weight. The interface avoids neon accents, playful badges, glass effects, gradients and oversized display typography.

## Foundations

- **Paper:** `#f5f2ea`; warm page background.
- **Surface:** `#fffefb`; focused project and media surfaces.
- **Ink:** `#112b2d`; primary text and actions.
- **Working note:** `#52615f`; readable secondary text.
- **Rule:** `#c9cec6`; quiet structure.
- **Muted gold:** `#9b7438`; rare active/progress cue.
- **Night:** `#0d292b`; experience and contact fields.
- **Display:** Manrope, weights 500–700. Never use compressed or extra-black display text.
- **Body:** Source Sans 3, weights 400–700, maximum reading width around 70 characters.

## Signature components

- **Identity:** André's circular portrait is the brand mark; the full portrait belongs only in About.
- **Hero:** an editorial statement with one dominant LinkedIn action and a secondary project link.
- **Experience bar:** the approved `4+ / 8+ / B2` evidence remains dark, compact and factual.
- **Core skills:** ruled rows remain; no badge cloud.
- **Project focus:** one selected case at a time, chosen from a horizontal top index.
- **Evidence player:** full-width 16:9 media, four four-second image slots, a full-to-empty project timer, manual controls, swipe and keyboard navigation.
- **Motion:** content enters once with a short fade/rise. Autoplay pauses on hover, focus, hidden tabs and when offscreen; reduced-motion disables it.

## Rules

- Keep the sticky navigation fully opaque.
- Use muted gold only for current state, progress and small metadata.
- Never invent data visualizations, metrics or client claims.
- Keep all owner-edited project content inside `content`.
- New project screenshots should ideally be 16:9 and at least 1600×900.
- Preserve EN/PT/ES, keyboard access and static GitHub Pages deployment.
